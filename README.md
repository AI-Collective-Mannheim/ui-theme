# AI Collective Theme & shadcn Registry

The canonical visual theme for all AI Collective Mannheim projects.

## Installation

### With shadcn CLI

```bash
npx shadcn add https://ai-collective-mannheim.github.io/ui-theme/theme.json
```

### With Tailwind CSS v4

Import the theme stylesheet into your main CSS file:

```css
@import "@ai-collective/ui-theme/src/tailwind-theme.css";
```

Or copy `src/theme.css` and `src/tailwind-theme.css` directly into your application.

## Palette

- **Primary / Brand Orange:** `#f9630e` (light) / `#fa7526` (dark)
- **Background:** `#f5f5f4` (light, warm stone) / `#0c0a09` (dark, warm carbon)
- **Card:** `#ffffff` (light) / `#1c1917` (dark, warm stone-900)
- **Radius:** `0.75rem` (`12px`)
